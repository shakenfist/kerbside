# shakenfist.kerbside

An Ansible collection for deploying
[Kerbside](https://github.com/shakenfist/kerbside), a SPICE VDI
protocol proxy, onto hosts you choose. It carries one role,
`shakenfist.kerbside.kerbside`.

This README is a placeholder. The role's variables are documented in
`roles/kerbside/meta/argument_specs.yml` until a full reference is
written here.
